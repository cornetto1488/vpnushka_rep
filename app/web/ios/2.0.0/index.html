Мобильные операторы

Канал не настроен нужен ваш документ на Яндекс.Диске

Отдельный канал для мобильного интернета: трафик идёт через Яндекс Документы. Хватает для мессенджеров, банков и госуслуг; для видео скорости мало.

Один документ — одно устройство. Для телефона и компьютера нужны разные документы, иначе они будут обрывать канал друг другу.

Самый быстрый способ
Войдите в Яндекс — документ создастся и настроится сам. Один вход, дальше ничего делать не нужно. Окно Яндекса появится, только если он попросит подтвердить вход.
Настроить вручную — своим документом
  1. Создайте документ на своём Яндекс.Диске
    Кнопка ниже откроет Диск. Нажмите Создать → Текстовый документ и напишите в нём что угодно (хоть одну букву), чтобы он сохранился.
  2. Откройте доступ по ссылке — на редактирование
    В документе: Поделиться → Доступ по ссылке → Редактирование, затем Копировать ссылку. Именно «Редактирование», иначе канал не поднимется.
  3. Вставьте ссылку сюда
    Ссылка выглядит так: https://disk.yandex.ru/i/XXXXXXXX

Технические настройки туннеля
Фрагментация TLS
Делит TLS-рукопожатие на части — помогает, если соединение с сервером рвётся на старте. «По пакетам» — деление на TCP-сегменты, «по TLS-записям» — деление самой записи TLS (быстрее, но помогает не везде). Каждое рукопожатие становится чуть медленнее.
Мультиплексирование (Mux)
На серверах с XTLS Vision mux не применяется — ядро не разрешает их вместе, такие серверы продолжают работать как обычно.
Виртуальный адаптер (TUN)
DNS
Ядро клиента — sing-box, поэтому здесь его настройки. Знакомые по XRay-клиентам «количество пакетов», «длина фрагмента» и «шумы» — это настройки другого ядра; их роль тут играют фрагментация TLS (по пакетам или по записям) и заполнение (padding) в mux.
Меняется конфигурация ядра sing-box — применяется при следующем подключении.
